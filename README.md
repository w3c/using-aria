Using ARIA
============

[![Netlify Status](https://api.netlify.com/api/v1/badges/efd418a3-7206-4674-9e00-44b0d0bfa251/deploy-status)](https://app.netlify.com/projects/using-aria/deploys)

**Using ARIA** is a Discontinued Draft published by the [Accessible Rich Internet Applications Working Group](https://www.w3.org/groups/wg/aria). The four rules of ARIA are retained for historical reference, and no further work on this document is planned. For guidance on using ARIA to add accessibility semantics to web design patterns and widgets, see the [ARIA Authoring Practices Guide (APG)](https://www.w3.org/WAI/ARIA/apg/).
